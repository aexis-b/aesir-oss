# Branding

## Project name

- primary name: `Aesir OSS`
- short name: `Aesir`

## One-line description

A local-first desktop shell for Hermes profiles, sessions, and transcript history.

## Slightly longer description

Aesir OSS discovers the Hermes installation already on your machine, reflects
its real profiles and sessions, and provides a calmer web and desktop shell for
browsing, resuming, and continuing work.

## Positioning

- local-first
- contributor-friendly
- Hermes-native rather than Hermes-replacing
- practical desktop tooling over agent spectacle

## Voice

- clear
- restrained
- technical without being cryptic
- trustworthy rather than hype-heavy
