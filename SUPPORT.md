# Support

## Where to ask what

- GitHub Issues
  - confirmed bugs
  - focused feature requests
  - actionable packaging or setup regressions
- GitHub Discussions
  - usage questions
  - environment setup help
  - broader product ideas

## Before opening an issue

- read the README and CONTRIBUTING guide
- check whether the problem already exists in open or closed issues
- include reproduction steps, logs, and platform details when relevant
- mention whether you are running web mode, desktop mode, Hermes CLI, or a provider fallback
